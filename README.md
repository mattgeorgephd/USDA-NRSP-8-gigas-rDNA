## WGS samples

32 samples were sequenced: 2 families (F05, F14) x 2 ploidies (2n, 3n) x 8 individuals. All 120 collected animals (4 families x 2 ploidies x 15) are listed in [morphometrics.xlsx](morphometrics/morphometrics.xlsx); the 32 sequenced are the first 8 of each F05/F14 ploidy group.

| Field | Value |
|---|---|
| Sample IDs | `F052n01`–`F052n08`, `F053n01`–`F053n08`, `F142n01`–`F142n08`, `F143n01`–`F143n08` |
| ID format | `F` + family (`05`,`14`) + ploidy (`2n`,`3n`) + individual (`01`–`08`) |
| Organism | *Crassostrea gigas* (whole-body tissue, collected 2022-11-14) |
| Origin | Pacific Hybreed families, reared at Jamestown Point Whitney Shellfish Hatchery |

| Extraction | E-Z 96 / EZNA Mollusc DNA kit (Omega D3373; [manual](manuals/D3373-Mollusc-DNA-Kit-Online.pdf)) |
| Customer QC | Qubit (fluorescence) + Nanodrop (spectrophotometry) |

## Progress
1. 20220728 - 4 Pacific Oyster families were generated by Pacific Hybreed and transfered to the Jamestown Point Whitney Shellfish Hatchery. Diploids and triploids were produced for each family using tetraploid crosses of parents.
2. 20221114 - Whole body oyster tissue samples collected. n=15 per family per ploidy.
3. 20230117 - Grace Leuchtenberger wrote up the DNA extraction protocol. Performed power analysis based on publicly available data. See [notebook post](https://mattgeorgephd.github.io/USDA-NRSP-8-gigas-rDNA-analysis-1/)
4. 20230202 - DNA extractions with Grace L and Henry Berg.
5. 20230314 - Shipped samples to Azenta (Short-read WGS, 30x coverage, 32 samples, 2 families, 8 samples per ploidy/family). See [notebook post](https://mattgeorgephd.github.io/USDA-NRSP-8-gigas-rDNA-analysis-2/) for more information.
6. 20230329 - WGS results received from Azenta. Stored on nightingales. Intial QC and trimming done on Raven. Files a bit big for this platform (maxed out drive). See [notebook post](https://mattgeorgephd.github.io/USDA-NRSP-8-gigas-rDNA-analysis-2/).
